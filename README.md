# Azure Sysadmin Labs

Repositorio de laboratorios prácticos de Microsoft Azure, documentados paso a paso durante mi formación como Administrador de Sistemas.

El objetivo es demostrar **experiencia real**, **buenas prácticas** y **razonamiento técnico** en cada servicio, con capturas de pantalla, comandos utilizados y conclusiones orientadas a un puesto de soporte IT L2.

##  Tecnologías y servicios practicados

- **Compute:** Azure VMs (Linux), App Service (Free F1), Azure Functions (Consumption)
- **Redes:** Virtual Network, Subnets, Network Security Groups (NSG)
- **Almacenamiento:** Storage Account con redundancia LRS, contenedores Blob privados
- **Identidad:** Microsoft Entra ID, RBAC, MFA con Microsoft Authenticator
- **Gobierno:** Cost Management + Budget + Alertas

---

##  Habilidades demostradas

- Despliegue de recursos en Azure desde el portal
- Configuración de red privada (VNet + NSG + reglas SSH)
- Creación y administración de identidades en Entra ID
- Validación del primer login con cambio de contraseña y MFA
- Análisis de costes y configuración de presupuestos
- Documentación técnica paso a paso orientada a soporte
