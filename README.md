# Azure Sysadmin Labs

Este repositorio contiene mis laboratorios prácticos de Microsoft Azure, documentados paso a paso mientras avanzo en mi formación como Administrador de Sistemas.  
El objetivo es demostrar experiencia real, buenas prácticas y razonamiento técnico en cada servicio que voy aprendiendo.

## Contenido del repositorio

- Fundamentos de Cloud y Azure
- Gestión de cuentas y presupuestos
- Máquinas virtuales (Linux y Windows)
- Redes virtuales (VNet, Subnets, NSG)
- Azure App Service y Functions
- Azure Storage (Blob)
- Microsoft Entra ID
- Cost Management

## Objetivo
Crear un portafolio técnico que muestre experiencia real en Azure y buenas prácticas de administración.
